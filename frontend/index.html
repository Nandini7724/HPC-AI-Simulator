About This Project

What is Deep Learning?

Deep Learning is a subset of Machine Learning that uses multi-layer neural networks to learn patterns from data. Training these networks requires repeated passes over large datasets, which is computationally expensive.

What is HPC?

High Performance Computing (HPC) uses powerful, often parallel, computing resources — multiple CPU cores, GPUs, and networked nodes — to solve computationally intensive problems efficiently.

Why Combine Them?

Large AI workloads require substantial computation and memory. HPC techniques such as multicore processing, GPU acceleration, data/model parallelism, and distributed computing allow these workloads to be processed more efficiently. This simulator lets you change hardware and workload parameters and observe, through a transparent mathematical model, how execution time, speedup, and efficiency respond.

Simulation Assumptions

  • Execution time is an estimate derived from a simplified mathematical model, not a measurement from real hardware.
  • CPU and GPU performance figures are abstract "reference" values, not benchmarks of specific real chips.
  • GPU behavior is modeled even when no physical GPU is present on the machine running this app.
  • Communication overhead is estimated from model size, bandwidth, and latency using a simplified all-reduce model, with one amortized synchronization event per epoch.
  • Memory behavior is simplified to a single working-set estimate (weights + gradients + optimizer state + one batch).
  • CPU/GPU/memory utilization figures are simulated, not readings from the user's actual machine.
  • This tool is intended for educational comparison of HPC concepts, not production capacity planning.
